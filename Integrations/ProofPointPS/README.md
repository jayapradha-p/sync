
# ProofPointPS

Proofpoint Email Protection stops malware and non-malware threats such as impostor email (also known as email fraud).

Python Version - V3_11
#### Parameters
|Name|Description|IsMandatory|Type|DefaultValue|
|----|-----------|-----------|----|------------|
|Api Root|None|True|String|https://{IP}:{Port}|
|Username|None|True|String||
|Password|None|True|Password|*****|
|Verify SSL|None|False|Boolean||



## Actions
#### Ping
Test ProofPoint Protection Server connectivity.
Timeout - 600 Seconds



#### Enrich Entities
Enrich entities with ProofPoint Email Protection.
Timeout - 600 Seconds
