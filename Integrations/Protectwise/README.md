
# Protectwise

ProtectWise™ provides automated network detection and response across time for any network. 

Python Version - V3_11
#### Parameters
|Name|Description|IsMandatory|Type|DefaultValue|
|----|-----------|-----------|----|------------|
|Email|None|True|String||
|Password|None|True|Password|*****|



## Actions
#### Ping
Test Connectivity
Timeout - 600 Seconds



#### Get Events
Get all events of an entity within a given timeframe
Timeout - 600 Seconds


|Name|Description|IsMandatory|Type|DefaultValue|
|----|-----------|-----------|----|------------|
|Timeframe (hours)|Fetch events in time frame of hours, e.g: 1|True|String||



#### Get Pcap
Download an event's packet capture
Timeout - 600 Seconds
